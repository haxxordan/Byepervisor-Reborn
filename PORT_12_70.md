# Firmware 12.70 port notes

This branch adds a standalone `byepervisor-1270.elf` target. The existing
`byepervisor_reborn.elf` entry point remains the default build. The 12.70
offset table is compiled only into the standalone target; the shared hook,
paging, and copy helpers also gain checks needed by the 12.70 path.
The 12.70 target is restricted to the launch model
(`sceKernelGetMainSocId() == 0x840f60`).

## Resume path

The payload checks the 12.70 kernel offsets, the fixed physical carrier at
`0x3ffff000`, the empty data cave, and the guest mappings before arming a
one-shot `#DB` hook on `hv_mp_startup_call`. The 224-byte AP stub runs during
S3 resume. It checks all 16 AP VMCBs, clears the nested-paging enable bit
in each control word and its related field at offset `0xc0`, then reports
its result through a kernel data-cave marker. The process waits
for resume, checks the marker and cleanup result, then reads the first eight
bytes of kernel text as proof that XOTEXT was cleared.

Before arming the hook, `textmap_1270.c` walks the entire `0xd50000`-byte
kernel text range. It accepts the two page layouts observed on the test
console: five or six 2 MiB leaves, with the rest mapped as 4 KiB pages.
Every targeted leaf must start as present, executable, XOTEXT, and read-only.
The code records unique leaf addresses, checks coverage and readback, then
clears XOTEXT and sets RW. It restores the original entries if preparation
fails. A successful resume leaves the changes active until reboot.

## Evidence and limits

On one launch-model 12.70 PS5, the one-ELF run completed a clean rest/resume
cycle. The USB result recorded:

```
textmap,planned,count=342
textmap,verified,count=342
result,bp=0x1270dbdb5eedbeef,ap=0x1270a9e17e5e2002,survey_count=16,...cleanup=0
end,vmcbs=16,text_entries=342,text_verified=342,text_read=0,first8=0x0000000058c55be8
```

The full kernel text range was also dumped in a separate test on this
console. The standalone target itself only reads and displays eight bytes;
it does not include a dump, Linux loader, or persistent patch set. The
12.70 offset table includes inherited candidate entries that this target
does not exercise; those entries should not be taken as proof that the
existing multi-firmware payload works on 12.70. The result is limited to
the tested model and firmware, and additional hardware runs are needed
before wider support can be claimed.

The original diagnostic sources and test history remain on the contributor's
`main` branch. This branch contains only the active 12.70 path and its build
dependencies for upstream review.
